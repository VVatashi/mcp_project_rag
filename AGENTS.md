## Доступные команды MCP Project RAG

- `projects.list`
  Возвращает список зарегистрированных проектов, доступных для индексации и поиска.

- `projects.register`
  Регистрирует локальный проект по `id` и `rootPath`, при необходимости обновляет существующую запись.

- `projects.unregister`
  Удаляет регистрацию проекта и очищает связанную Chroma collection.

- `index.run`
  Сканирует проект, режет код и документацию на чанки и полностью перестраивает индекс проекта в ChromaDB.

- `search.query`
  Выполняет retrieval + rerank по конкретному проекту и возвращает наиболее релевантные фрагменты без финальной сборки контекста.

- `context.build`
  Собирает компактный, готовый к передаче агенту контекст по проекту под конкретную задачу или запрос.
